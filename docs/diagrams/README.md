# UML diagram sources and exports

The `.puml` files are the editable, authoritative sources for the diagrams. All five checked-in `.svg` previews were regenerated from their matching sources with PlantUML 1.2026.10 on 2026-11-15. After editing a source, run `java -jar plantuml.jar -tsvg <source>.puml`, name the generated export to match the `.puml` file, review it, and commit both files.
